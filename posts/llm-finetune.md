以 Llama 为例，详解监督微调、奖励建模与强化学习对齐的全流程。

## 微调路线图

```
预训练模型 → SFT → 奖励模型 → RLHF → 对齐后的模型
```

## SFT：让模型学会对话

监督微调是最基础的一步。数据格式通常是：

```json
{
  "instruction": "请解释什么是过拟合",
  "output": "过拟合是指模型在训练数据上表现很好..."
}
```

使用 QLoRA 技术，在单张消费级 GPU 上即可微调 7B 模型。

## 奖励模型训练

奖励模型用来给生成结果打分。核心是构造偏好数据对（preference pair），让模型学习人类偏好。

## RLHF：强化学习对齐

PPO 算法是当前主流选择。关键技巧：

- KL 散度约束防止模型偏离太远
- 梯度裁剪保持训练稳定
- 小批量更新减少算力消耗
